# ألعاب العربية للصف الثامن

الصفحة الرئيسية: `index.html`
اللعبة الحالية: `interactive.html`

## تفعيل GitHub Pages
افتح https://github.com/mmohamed-maker/Grade-8/settings/pages
- تحت Build and deployment اختر Source: Deploy from a branch.
- اختر Branch: main والمجلد /(root)، ثم Save.
- انتظر اكتمال النشر وظهور رابط الموقع في الإعدادات.

الروابط المتوقعة بعد تفعيل النشر:
- المكتبة: https://mmohamed-maker.github.io/Grade-8/
- اللعبة: https://mmohamed-maker.github.io/Grade-8/interactive.html

## المشاركة على Schoology
من Materials اختر Add Materials ثم Add File/Link/External Tool ثم Link، وألصق رابط اللعبة أو المكتبة. افتح الرابط في نافذة جديدة إذا منع النظام العرض المضمن. لا تُرسل الدرجات أو التأملات تلقائيًا إلى Schoology؛ يمكن للطالب إرفاق لقطة لبطاقة الإنجاز في واجب.

## إضافة لعبة
ارفع ملف HTML باسم إنجليزي واضح، مثل vocabulary.html، إلى المستودع. أضف بطاقة في index.html تشير إلى ./vocabulary.html. إذا احتاجت اللعبة ملفات صور أو صوت، ارفعها معها واستخدم مسارات نسبية. تجنب وضع مفاتيح API أو بيانات الطلاب في الملفات العامة.

## الإصلاحات
- الحد الأقصى مشتق من بيانات الأسئلة: 5 × 10 + 3 × 15 + 25 = 120.
- خلط الجمل عند بدء كل محاولة، مع ضمان ألا تبدأ محلولة.
- منح نقاط الترتيب مرة واحدة وقفل الترتيب بعد النجاح.
- منع الانتقال بعد ترتيب خاطئ، ومنع تكرار احتساب إجابات المستويين الأول والثاني.
- رابط رجوع إلى المكتبة وتسميات لأزرار تحريك الجمل.

## التحقق
اجتاز JavaScript فحص الصياغة واختبارات منطقية بمحاكاة عناصر الصفحة: 500 بداية مخلوطة، وعدم تجاوز ترتيب خاطئ، وعدم تكرار نقاط الترتيب، وقفل الجمل بعد الحل، وإعادة ضبط المحاولة.
لم يُختبر العرض في متصفح لعدم توفره أثناء التعديل. تعتمد اللعبة الحالية على خدمات خارجية للخطوط والأيقونات وTailwind؛ يلزم اتصال بالإنترنت.
